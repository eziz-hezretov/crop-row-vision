# Dataset

This project was tested using agricultural field images from the
Crop Row Detection Lincoln Dataset (CRDLD).

The raw dataset is not stored in this repository.

To reproduce the experiments, obtain appropriate agricultural field
images from the original dataset source and place them in:

data/raw/

The test set used for this project included images representing
different field conditions such as clear rows, shadows, sparse weeds,
dense weeds, curved rows, and larger crop growth.

The dataset remains subject to its original authors' licensing and
usage terms. The license for this repository applies only to the code
written for this project.
